# 本地缓存、采集状态与局域网连接

App 的订单和取件记录仍以原生 SQLite 为本地权威数据源。启动先读取本地快照；初始化与并发页面读取复用结果，近期快照使用短时内存缓存。页面加载完成之前显示“正在读取本地记录”，不把未读取状态误称为未绑定。首屏呈现后再执行自动短信扫描及后台同步；同步中显示进度并保留已有记录及上次成功同步时间。网络故障不清除绑定和历史数据。

采集任务执行结果与分项信息完整度分开：`completed` 携带日期或物流缺失时显示提示，不作为整轮失败；真实 `error/expired/disabled` 仍显示错误。后台快照携带授权范围内每个账号/订单作用域的最新任务摘要，包含单调推进的时间字段，持久化后可恢复。App 以摘要更新旧提示并保护更新的本地在途任务，兼容不提供摘要的旧后台。包裹页“重试”实际发起刷新并复用在途请求。

## 配置局域网入口

在后台“服务设置”填写可选的“局域网 HTTPS 地址”。环境变量配置方式可使用 `LAN_BASE_URL`。省略或清空时仅使用原来的外网地址。局域网地址必须是完整 HTTPS origin（协议、域名和可选端口），不能包含账号密码、路径、查询参数或片段；内网反向代理须有匹配域名的有效证书。后台不会通过 Docker 网桥地址猜测手机可达地址。

设备经原绑定地址读取 `/v1/connection`，缓存 `lanBaseUrl` 与稳定的 `serviceId`。手机无需单独填写内网地址；首次获取或变更配置时须能连通原绑定入口，已缓存的可信地址可在外网入口故障时继续使用。选择局域网前用不带凭证的 `/health` 短时探测并核对实例身份；仅可信配置中的匹配服务会收到设备授权。探测结果短时缓存，网络变化后重新判断；失败回退原外网地址。选路不改变原绑定身份、授权范围或本地订单归属。

API 的 GET 在局域网传输失败时可以回退外网；鉴权错误、重定向和写操作不会被盲目重放。更新检查与下载使用同一套已验证地址顺序，依次尝试局域网后台、外网后台、GitHub；每次下载切换来源都从空文件开始，并继续校验摘要、大小、包名、版本和签名。更新资源请求不携带设备令牌。

正式版保持 HTTPS 限制。Android 调试版本仅允许本机 loopback HTTP，用于 ADB reverse 隔离测试；这不开放实际局域网明文连接。

App 3.1.22 与后台 3.1.17 配套使用。保留原数据卷和密钥更新后台，再覆盖安装同签名 App 并同步，无需重新绑定。发布安装包和镜像不会自动更新正在运行的 NAS 容器，也不会配置路由器或申请证书。模拟器验证使用独立临时数据；真实后台联调需为模拟器单独绑定授权。
