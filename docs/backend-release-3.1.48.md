# App 与后台 3.1.48 · 审计修复

App **3.1.48 / 30148** 配套后台 **3.1.48**，插件保持 **1.2.1**。本轮只修复既有问题。

## 修复内容

- 物流明确反馈“未收到包裹/未收货”时阻止或撤回自动已取。启动时纠正存量错误；人工领取和撤销仍优先。客服条件提示“如未收到请联系”不会当成实际未收反馈。
- 拼多多待收货列表缺少运单时进入原有受预算、冷却控制的详情补查；详情验证的新运单作为独立包裹接纳。旧单、人工领取、隐藏和归档状态保留，不自动替换或转移。
- Android 放行识别异常报告和站点规则回执的两条精确 POST 路径，保留原鉴权和其它路径限制。
- 异常报告取消携带短信真实取件码和短信单号；核心生成、H5/Android 发送边界及后台保存均处理，旧队列与旧后台任务也清理。保留任务版本、完成状态、重试预算、attempt 和 AI 审核关联。短信本地匹配继续使用原值。
- 绑定核验及 FAQ 明确自建后台接收的问题元数据：候选包裹 ID、承运商、时间、原因与处理状态。原短信不上传；站点片段仍受既有开关及脱敏控制。真实解除部分包裹关联后，问题可以重新处理。
- 站点地区保存拒绝联系方式、单号及取件码；AI 请求出站再次脱敏，覆盖历史目录/候选。目录历史不被删除或改写。
- 首页添加和更新按钮支持 Tab、Enter、空格、禁用及可见焦点；输入框的真实控件具有名称。处理 uni-app 键盘事件包装，避免单测与实际页面不一致。

## 开发依赖与剩余风险

Vite 升至 **6.4.6**，使用有限 npm overrides 修补可兼容的传递依赖，保持 DCloud/Vue 同期组合；最低开发 Node 为 22.12，推荐既有构建环境 Node 24.13+。未使用 force、忽略告警或绕过 peer 检查。

开发服务保持本机监听，明确启用严格文件范围、仅允许项目根及本地 CORS。正常安装、生产构建、Vue/SCSS 热更新、跨源请求、WebSocket 和目录外文件读取已在隔离工作副本实际验证。

App 完整 npm 审计由 **33 个受影响包条目降至 14 个（8 high、6 moderate）**，尚未清零。剩余直接叶项为 Vue server-renderer 的 [SSR 属性渲染漏洞](https://github.com/vuejs/core/security/advisories/GHSA-g2v6-rqmx-r4w6)，以及 Intlify 的 [HTML 翻译属性](https://github.com/intlify/vue-i18n/security/advisories/GHSA-x8qp-wqqm-57ph)和[参数转义漏洞](https://github.com/intlify/vue-i18n/security/advisories/GHSA-8rc2-428q-7ww3)。当前 App 只构建静态 H5，不运行 SSR，也没有对应 HTML 翻译调用；后续启用这些路径前必须重新评估。条目数包含上层依赖的传递告警，不等同独立漏洞数，不能据此宣称零风险。
