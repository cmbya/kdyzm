# App 3.1.37 / 后台 3.1.33

App 打开“我的”和线上账号时先读取已有的本地统计和账号，显示后再连接后台。同步进行中或连接失败时保留已有内容；没有缓存的首次使用仍需完成初次读取或同步。

本轮持久化显示快照、提供轻量统计与账号读取、减少同步中重复计算，并合并页面与原生任务重复发起的自动同步。手动强制刷新和绑定切换仍按原规则处理，旧回复不会覆盖新绑定的数据。

后台 3.1.33 同步更新服务版本及镜像标识，内置 App 3.1.37 安装包。现有后台接口保持兼容；要获得本轮页面显示优化，需要更新手机 App。

## 升级

1. 拉取 `ghcr.io/zsdd2/kdyzm:3.1.33` 或 `ghcr.io/zsdd2/kdyzm:latest` 并重建容器，保留原数据卷和加密密钥。
2. 手机进入“我的 → 检查更新”，或从 [App Release](https://github.com/zsdd2/kdyzm/releases/tag/app-v3.1.37) 下载 APK 覆盖安装。沿用原签名，无需卸载或重新绑定。

升级会增加本地衍生显示缓存，原短信、包裹、领取记录与绑定保留。第一次生成缓存和网络同步仍可能需要等待。Chrome 插件保持 1.2.0。

## 验证边界

本地缓存、同步合并与过期回复保护已通过自动回归；隔离原生桥下已验证同步挂起和失败时保留数据显示。桌面合成数据验证了重复计算下降，实际手机速度仍取决于设备和数据量，未将桌面结果当作真机耗时。
