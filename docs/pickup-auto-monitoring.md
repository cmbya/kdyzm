# 取件自动监测

本轮本地实施保持方案A布局，修复大卡片文字重叠，并增加默认开启的取件自动监测。

## 使用行为

- 后台同步每条运单的轨迹，确认本人签收、收件人领取成功、用户已取走等明确事实后，自动移入已完成。总数、取件列表和卡片同步扣除对应包裹，多运单订单只改变已经领取的运单。
- 驿站代收、普通签收、门口投递、交易完成、无主体的取件成功、否定、指令、疑问和时间冲突都不会自动完成。
- 包裹详情显示完成时间和原始依据。撤销自动完成后维持人工未取状态，后续同步不能覆盖；可手动取件，也可恢复自动判断。即使旧自动证据被撤回，恢复入口仍保留。
- 后台“服务设置 → 取件自动监测”可查看开关、监测关键词、AI建议、变更记录和回滚。手机设置展示后台状态及完成记录，首页通知不增加待处理数量，隐藏或已撤权记录不会进入最近完成。

## AI监测词

监测与AI调优默认开启。内置规则不依赖AI服务；AI追加词组需要后台已有可用的默认AI服务和全局开关。

支持多组关键词，组间独立命中；每组可以包含多个必须同时出现的词。AI从新轨迹中选择完整领取措辞，追加并优化监测词组，重复词去重、冗余条件等价缩减。原始轨迹先经过严格语义检查，只有脱敏的主体和完成动作发送给AI。

每次建议必须通过否定、代收、未来、疑问等反例与缓存轨迹回放。模型不能修改系统约束或生成可执行规则。调优遵守现有6小时检查、新证据触发、共享额度和重试限制；同一证据不会无限调用。回滚会重算自动结果，人工选择保留。

## 大卡片

保留站点筛选、平台筛选和5.2秒自动切换，取消旧的半页滑动叠加。原生大卡片和设置页预览均改为整页直接切换，避免上下两页文字和页脚在动画过程中重叠。
