# App 3.1.44 / 后台 3.1.40

京东、拼多多、淘宝分别优化物流读取；修复淘宝明确已从代收点取出却未更新助手状态的问题。

- 京东：校验拆单完整性，同一取件周期内恢复有效取件码。
- 拼多多：校验订单、运单与柜码归属，补全单笔和有明确平台参数的分包柜码读取；局部失败保留已成功轨迹。
- 淘宝：完善富文本、完整时间和独立分包详情读取，核对运单归属；同一已取事实转为历史展示后保持已取。
- 共用：保留时间与平台状态冲突证据，避免异常记录覆盖可信状态；人工恢复待取继续优先。

详细规则见 [分平台读取优化](platform-reading-accuracy.md) 和 [淘宝读取修复](taobao-reading-optimization.md)。回归覆盖空节点、拆单缺包、取件周期、运单串包、时间冲突和失败重试；按现有完整发布门禁验证 App、后台、H5 与 Android 构建、原生测试、lint 及密钥扫描。

升级时先拉取 ghcr.io/zsdd2/kdyzm:3.1.40 或 latest，保留原数据卷、加密密钥及部署配置重建容器，再覆盖安装原签名 App 3.1.44 / 30144，或在“我的 → 检查更新”升级。无需清库、卸载或重新绑定。插件仍为1.2.0。

新增淘宝分包详情和拼多多分包柜码链路已核对官方参数并通过隔离验证，尚未用真实登录多包订单和实体手机逐一验收。部分拆单补查增加请求数，未测量线上准确率或整体耗时。发布安装包及镜像不代表用户 NAS 或手机已升级；未运行 nightly / Semgrep。
