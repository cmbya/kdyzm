# App 3.1.42 / 后台 3.1.38

本轮修复Android内微缩物流PNG不显示，保留 [App 3.1.41](miniature-journey-3.1.41.md) 的站台、小车、拖车、真实事件定位、路面耗时及完成收拢设计。App版本为 **3.1.42 / 30142**，沿用原签名；后台 **3.1.38** 仅内置新版安装包，无业务逻辑或数据库变更；插件仍为 **1.2.0**。发布和镜像校验结果以最终发布记录为准。

## 根因与修复

微缩物流组件运行时使用 `/static/...` 引用PNG。Android WebView将以 `/` 开头的路径解析到appassets根目录，请求返回403，导致这些素材不显示。浏览器可显示同一界面，并不能证明Android安装包内的资源路径正确。

本版将这些引用改为 `./static/...`，使其相对于App页面解析，正确加载 `/assets/app/static/` 内的PNG。修复只涉及资源路径，不改变物流阶段判断、时间计算或已有卡片交互。

## 发布后的升级方式

1. 拉取 `ghcr.io/zsdd2/kdyzm:3.1.38` 或 `ghcr.io/zsdd2/kdyzm:latest`，保留原数据卷、加密密钥和部署配置，重建容器。
2. 使用“我的 → 检查更新”，或下载本轮原签名APK覆盖安装。不要先卸载App。
3. 打开取件卡片、包裹记录或订单详情，检查微缩物流素材是否正常显示。

升级无需清库、重建数据库或重新绑定，保留原应用数据。不要删除数据卷，也不要执行 `docker compose down -v`。更新镜像不会自动替换正在运行的NAS容器，需按上述步骤重建。
