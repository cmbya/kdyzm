# App 3.1.29 / 后台 3.1.25：取件自动监测

日期：2026-11-06。名称：取件自动监测。

## 发布内容

- 取件自动监测默认开启。后台同步每条运单的轨迹，只有明确表示本人、收件人或用户已经实际领取、取走、取件的证据，才按对应运单自动移入已完成；多运单订单只完成有证据的运单。
- 普通签收、驿站代收、门口投递、交易完成、无主体的领取成功，以及否定、指令、疑问、未来或时间冲突语句不会自动完成。
- 包裹详情保留完成时间和原始依据。人工撤销自动完成后优先保持未取，后续同步不能覆盖；可以手动完成，也可以恢复自动判断。回滚或撤回旧自动证据时保留人工选择。
- 后台“服务设置 → 取件自动监测”提供开关、监测词组、AI建议、变更记录和回滚；手机设置展示后台状态与完成记录。

## 关键词与AI

内置监测规则无需AI即可工作。AI调优默认开启，需要后台已配置可用的默认AI服务和全局开关。支持多组关键词，组间独立命中，同组关键词必须同时出现。AI从新轨迹中提取完整领取措辞，追加并优化词组，重复词去重、冗余条件作等价缩减；原始轨迹先做严格语义和脱敏处理，只发送主体与完成动作。

每条建议都要通过否定、代收、未来、疑问等反例与缓存轨迹回放；模型不能修改系统约束或生成可执行规则。调优遵守既有周期、新证据触发、共享额度和重试限制，同一证据不会无限调用。建议应用后可回滚，并重新计算自动结果，人工选择保留。

## 大卡片与升级

保留站点、平台筛选和5.2秒自动切换。原生大卡片及设置页预览均采用整页直接切换，不再使用旧的半页滑动叠加，避免上下页面文字和页脚重叠。

App使用原签名覆盖升级，不要先卸载，已有绑定、取件记录和设置保留。已有NAS需要拉取新镜像，保留原数据卷、加密密钥和设备绑定后重建后台容器；插件保持1.2.0。真实AI服务与OPPO实体手机仍需现场验收。
