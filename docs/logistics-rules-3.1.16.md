# 物流识别规则：后台3.1.16 / App3.1.21

补齐“已暂存至/到/于/在”等物流表述，提取末端站点及真实到站时间。保留未来、否定、请求、中转、退回和催取保护；普通商店收件地址不会自动当作取件点。规则识别成功不等于包裹必然合并，自动关联仍需符合站点、时间、双方唯一和冲突限制。

App入口为「我的 → 物流识别规则」，仅本机保存，不上传后台，也不会被订单同步覆盖。编辑、启停、删除或恢复默认后重新核对已有物流，保留人工领取、隐藏和现有关联。

后台入口为「服务设置 → 物流识别规则」，由管理员独立维护。修改草稿、样例测试均不保存；点击「保存规则」后，下次成功采集或刷新物流时使用。保存本身不会回填真实订单。多人同时编辑时拒绝旧版本覆盖，保留当前草稿。

两端均支持新增、编辑、启停、删除、样例测试及恢复默认。填写站名前文字、可选结束文字、必含关键词、样例与预期站名；使用明文模板，不执行脚本或任意正则。到站事件规则提供到站证据，仅位置规则只提取站名。原有站点别名和AI人工核对流程不变。

更新时保留后台完整数据卷与加密密钥，拉取新镜像并重建容器，再覆盖安装同签名App并同步，无需重绑。App规则与后台规则互不覆盖，需要分别维护。

本轮验证覆盖App264项、后台镜像237项、JVM135项及H5/Android构建，另有独立发行仓库测试、依赖审计和容器CI门禁。已在本机模拟数据完成手机/桌面规则编辑、测试、保存与重载验证；未操作生产模板、真实订单或真实AI服务，实体手机安装仍需实际验收。
