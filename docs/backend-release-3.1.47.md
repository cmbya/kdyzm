# 后台 3.1.47 · 京东商品图片修复

修复京东未收订单的商品图片缺失。后台读取京东当前接口的 `wareList[].imgPath`，同时保留旧 `imageUrl/imgUrl` 字段兼容；图片继续通过原有 HTTPS 和平台域名校验。

只采集当前未收到及新增包裹的图片。已有未收订单缺图时，升级后下一次正常完整采集可补齐；历史完成订单仍忽略，不回填历史图片。

## 手动升级

拉取 `ghcr.io/zsdd2/kdyzm:3.1.47` 或 `ghcr.io/zsdd2/kdyzm:latest`，保留原数据卷、加密密钥和配置重建容器。后台版本应显示 3.1.47，再等待正常完整采集或手动执行京东账号采集。

App 保持 **3.1.47 / 30147**，Chrome 插件保持 **1.2.1**，两者无需为本次修复更新。镜像继续内置原 App 升级包，GitHub Latest Release 保持 App 3.1.47。无需清库、卸载或重新绑定；NAS 由使用者自行升级。

## 验证

回归覆盖当前图片字段、旧字段回退、非法地址拒绝、订单图片隔离、历史订单过滤，以及采集器→存储→App 同步后为已有未收订单补图。已在雷电 App 3.1.47 中使用真实公开商品图片和合成订单验证正常加载。

未修改生产订单或代为升级 NAS；线上订单需更新后台并重新完整采集后确认。
