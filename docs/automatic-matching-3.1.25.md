# 自动调优与历史匹配修复

配套版本：App **3.1.25 / 30125**，后台 **3.1.22**。插件维持1.2.0。

## 一次设置，自动处理

保留原数据卷与加密密钥更新后台，覆盖安装App并同步，无需重新绑定。在后台「服务设置 → 站点管理 → AI待核对 → AI设置」选择已配置渠道，开启「启用自动优化」及「自动调优（站点＋物流）」并保存。手机开启「站点片段增强」后，收到短信自动提交允许的脱敏站点片段。旧设置不会静默开启自动修改。

后台持续处理未识别材料，生成结果后自动验证。有唯一具体依据的站点别名加入已有站点；物流规则通过到站语义、具体公共站点、反例及缓存语料回放后自动生效。结果随手机同步重新核对既有短信与订单，不必反复点“分析”。手机成功提交候选后安排约30秒回读，开启增强期间每15分钟检查；Android节电与离线可能延迟执行。

存在冲突、缺少证据或超出验证范围时仍保留待核对。AI不会仅凭“包裹数量相等”关联，不自动合并或创建标准站，不更改领取/收货状态，不覆盖人工规则。短信识别模板仍保留确认步骤；本次自动应用范围是站点别名和物流识别。

## 自动修改可追溯、可撤回

「最近自动优化」记录每次站点别名或物流规则修改，可撤回单条。撤回只移除该次新增内容；若人工之后已修改相关内容，拒绝覆盖并提示核对。新增、停用、删除和撤回规则都会重新计算缓存，并同步到手机。关闭自动调优后继续保留建议模式。

## 这次解决的匹配问题

- 已确认的站点别名仍未匹配：升级后重新计算旧物流投影，不再被旧缓存阻断。
- 短信与到站相差超过一分钟：AI队列使用匹配候选的完整有效范围，不再独立卡在60秒。
- 后台能识别、手机仍不匹配：后台物流规则作为只读层同步，手机重算保留这些规则，本机同ID规则优先。

保留双方唯一、承运商/站点/时间证据、人工解除、已取及跨角色保护。仅时间或数量接近不足以自动关联。

## 验证边界

自动调优整链使用合成供应商及脱敏样例验证，覆盖应用、缓存重算、手机匹配和撤回。能力测试检查输出结构和样例提取，不代表真实模型准确率。真实供应商速度/兼容性与实体手机仍需实际使用验证；发布代码和镜像不会自动更新现有NAS容器或开启生产AI配置。
