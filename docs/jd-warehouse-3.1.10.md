# 京东出库阶段物流修复

服务端3.1.10，配套App3.1.13 / 30113。

## 原因与行为

京东订单列表仍显示“等待出库／正在出库”时，详情页可能已经有运单和“仓库处理中：您的订单已经打印完成”轨迹。3.1.9只为运输中或已有活动运单的订单查询详情。此前没有运单的出库订单也不会进入自动补查集合，普通同步因此可能一直保存空物流，直到列表变为待收货或用户主动刷新单笔。

3.1.10将明确待发货和出库订单也纳入详情查询，保留每轮20次预算、按上次查询时间轮转及人工完成运单的排除规则。没有实际单号时仍保留无运单订单，不生成虚构物流；打印完成只说明仓库处理，不据此改成运输中。已有轨迹继续按原协议发送到App。

App3.1.13修复组件的配套边界：已预生成单号、实际尚未发货的订单仍显示“待发货”。到站和运输轨迹优先，签收、隐藏、归档筛选继续生效。记录页和物流详情沿用现有布局，淘／拼／京标记与十字商品名规则保留。
