# App 3.1.43 / 后台 3.1.39

## 取件分享

取件页右上角分享按钮打开勾选窗口，默认全选当前到货待取项目。按站点生成紧凑票据，显示柜号、取件码、快递、最多15字商品名和件数；不放订单号、价格、短信全文。支持没有关联订单的短信码及手工待取码，已取件项目不参与。每张最多40件，超出大小限制可分批。Android系统保存与分享复用可信桥和独立文件提供组件，无新增存储权限；打开分享窗口不代表已经发送给他人。

用户从三张官方 Images API gpt-image-2.6-sunburst 方案中选择B。批准稿见 [B紧凑票据卡](designs/pickup-share-b.png)，[Figma对照](https://www.figma.com/design/8vZ33CfpH5T718wSficdf0?node-id=123-3)。

“已存放至快递超市”等明确完成事件在当次解析识别。已有站点不再阻断缺失时间补全；后台启动与App快照重算均可回填已有可靠证据，AI关闭也生效。保留可信时间及精度、人工站点和柜机证据。原始时间与时间戳冲突、未来、预计、退回和催取不补造到货时间。平台采集冷却保持原值，不把查询时间当作事件时间。
