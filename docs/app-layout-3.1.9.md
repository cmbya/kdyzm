# App 3.1.9：记录排版与大组件

用户确认包裹记录方案2和大组件A。记录页保留原蓝白主题、时间轴、平台卡片、三标签导航与添加按钮；商品和单次金额位于上行，取件码／站点或当前状态在下行，取件按钮固定右侧。家人名为浅灰背景文字，不阻挡点击。订单号、运单号、复制、日期、隐藏和更多仍可展开操作；多运单摘要优先显示尚未领取的包裹，并提供总数入口。

5×3大号桌面卡片上部显示待取码、站点、家人、件数和商品摘要，下部独立显示路上订单。没有取件码的待发货、运输中和到站待取码订单也能进入下区；未人工领取的物流签收保持准确状态。隐藏、删除、已领取、取消与明确退款完成记录不进入路上区，交易完成但仍有活动物流的订单保留。共码进入App逐件确认；单件快取提供7秒撤销，只能撤销该次操作且后续编辑会使撤销失效。隐私模式隐藏取件码、站点、家人和商品。
