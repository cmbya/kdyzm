# 淘宝已取状态与插件首次同步修复

后台3.1.42、登录同步插件1.2.1；App保持3.1.44。

## 修复内容

淘宝已经明确返回“包裹已从代收点取出”，但助手仍待取：完整轨迹与淘宝摘要合并后附带了平台字段，旧版将这些完整时间排除，导致历史运输摘要一直没有时间、持续阻止已取判断。本版依据同运单完整且一致的时间补齐旧摘要；升级后的首次成功采集会重新计算旧缓存。

普通签收、未知退回、重新入库、冲突时间和其他运单不能据此自动完成；人工“恢复待取”仍优先。

插件首次核对账号时，定时刷新可能与预览并发，错误取消已选择的平台。1.2.1处理响应先后顺序，保留有效的本次选择；真实授权撤销、账号切换和用户取消仍生效。无需因这类错误反复创建角色授权。

## 更新方法

保留原数据卷和密钥，拉取后台 `ghcr.io/zsdd2/kdyzm:3.1.42` 并重建容器。使用[插件1.2.1更新包](https://github.com/zsdd2/kdyzm/releases/tag/cookie-extension-v1.2.1)更新原插件目录，再重新加载原扩展实例。已有有效授权继续使用；本轮无需更新App。

后台更新后执行一次淘宝采集，再同步App。若此前手动设置过“恢复待取”，需要在App恢复自动判断。
