# App 3.1.23 · 包裹记录单页总览

包裹记录默认展示全部平台，上方增加平台与进度统计。点击淘宝、京东、拼多多或某个进度即可在原页筛选；两个条件取交集，再次点击取消该条件，清除筛选同时取消平台与进度。列表轻动效更新，统计和操作按钮保留位置。

每张订单卡保留彩色角色票签，颜色由稳定角色ID决定；同名角色不合并，未确认角色显示“待归属”。角色、时间和隐藏记录集中在一个筛选面板。

默认展示最近45天内全部进度，包括已完成订单。更早历史可以主动显示；仍有未领取取件码的旧订单继续保留。订单与有号运单分别统计，一单多运单按对应进度计算，混合订单在已完成筛选中标注“部分已完成”。物流签收和交易成功不会自动变成用户已领取。

详情使用底部面板，保留复制、物流、逐运单取件/收货确认与撤销、日期修改/恢复、手动记录编辑和隐藏恢复。使用原有本地快照与后台接口，更新中和断网继续显示已有记录；迟到旧快照不会覆盖已经收到的新结果。
