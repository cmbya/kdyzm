# 取件助手 · Chrome 登录同步插件 1.0.0

支持淘宝、拼多多和京东网页登录信息的一键同步，以及主动开启后的自动同步。配对对象是后台的一个具体平台账号，包含该账号的家人归属。

## 安装

1. 将插件压缩包解压到固定目录。不要直接打开压缩包中的文件。
2. Chrome 地址栏打开 `chrome://extensions/`，打开“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 在浏览器扩展菜单找到“取件助手 · 登录同步”，点击打开设置页。可以将它固定到工具栏。

这是本地加载版，不需要上架商店。保持目录位置不变；插件更新时替换目录中的程序文件，再在扩展管理页点击重新加载。浏览器中的账号配对保存在当前 Chrome 用户配置里，不通过 Chrome 账号云同步。

## 配对与使用

必须先更新后台至 3.1.18 或更新版本，包含 `/v1/cookie-sync/` 接口；3.1.17 及更早版本不含这些接口，单独安装插件不会让旧后台自动增加功能。已安装插件 1.0.0 的用户无需重装插件，只需更新后台后配对。

1. 登录后台，在“账号授权”选中家人，打开已有平台账号的“详情”。
2. 找到“浏览器 Cookie 同步”，点击“生成一次性配对”，再点“复制插件配对信息”。
3. 粘贴到插件的“添加配对”。读取并核对后台地址、家人、平台和账号，再确认配对，并按 Chrome 提示授权这些站点。
4. 点击“打开登录页”，在平台官方网站正常登录。京东须使用网页版订单登录，单独手机 Cookie 不受支持。
5. 返回插件，点“读取并核对登录”，核对目标后确认首次同步。插件不会展示 Cookie 原文。
6. 需要自动更新时，开启该账号的“登录信息变化时自动同步”。可以分别为不同家人、平台添加配对。

配对码十分钟内一次有效。授权最长九十天；同一后台账号重新配对会撤销旧插件授权。后台调整账号的家人归属会立即撤销原插件授权，移回原家人也不会恢复。插件和后台账号详情均可撤销授权。

## 自动同步的边界

- 自动同步默认关闭。开启后，监听 Cookie 变化约三十秒后处理，并每五分钟补查；Chrome 休眠或退出会延迟执行。
- 只在浏览器账号标识与后台授权账号匹配时上传。标识缺失、冲突或切换到其他账号时停止该次上传，不猜测家人；切回正确账号后可以继续。
- 同一 Chrome 用户配置中的同一平台通常共享当前登录状态。若需要多个家人账号同时保持登录，分别使用 Chrome 用户配置文件，并在各自配置里配对对应账号。
- 身份匹配使用淘宝 `unb`、拼多多 `pdd_user_id/pdduid`、京东 `pin/pt_pin`。这是网页登录信息中的稳定标识校验，不是平台官方身份认证协议；平台改变字段时需更新适配，缺少标识时使用原后台手动更新入口。
- 上传成功只代表登录信息已保存。后台随后按原采集冷却验证；验证码、风控、退出登录或平台拒绝访问仍可能需要本人重新登录。扩展不输入密码、不处理验证码，也不自动购买或确认收货。
- 浏览器中可读取 HttpOnly Cookie；不同隐私窗口、其他 Chrome 用户配置、手机 App 的登录信息不会混读。

## 数据与权限

按实际配对申请后台地址和对应平台的站点权限；没有网页内容脚本，也没有默认永久授权所有站点。仅在受信任的扩展设置页操作，不接受普通网页向插件发出同步指令。

插件只保存后台地址、账号摘要、独立同步令牌、自动开关和上次 Cookie 摘要，不保存管理员密码或 Cookie 原文。令牌保存在当前 Chrome 配置的本地扩展存储中，具有该账号的写入权限，请保护电脑和浏览器配置。Cookie 在内存中读取，通过 HTTPS 发送至配对后台并沿用后台加密存储；只有本机开发测试允许 loopback HTTP。请求禁止重定向，不向第三方同步平台发送登录信息。

原后台管理员登录和 App 设备授权保持独立。插件令牌不能查询订单、访问管理员接口或修改其他账号；首次身份绑定须人工确认，之后同账号更新受版本检查保护，避免旧在途请求覆盖较新登录信息。

开发验收使用独立浏览器配置、临时后台与合成 Cookie；并不表示已验证每个平台真实账号的长期有效期或当前风控策略。
